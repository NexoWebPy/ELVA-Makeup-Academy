# ELVA-Makeup-Academy
ELVA Beauty Academy es una academia de formación presencial en maquillaje y belleza ubicada en Itauguá, Paraguay. Ofrece experiencias de aprendizaje orientadas a desarrollar habilidades, potenciar la creatividad y descubrir el talento de cada estudiante, combinando técnicas, práctica y pasión por el mundo de la belleza.
