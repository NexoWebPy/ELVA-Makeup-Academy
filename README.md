# ELVA Beauty Academy 💄

### Plataforma web institucional para una academia de belleza y maquillaje.

Desarrollada por **NexoWebPy**, esta página web presenta la identidad de ELVA Beauty Academy, sus formaciones, cursos, servicios y propuesta educativa mediante una experiencia visual moderna, elegante y adaptable a distintos dispositivos.

---

## ✨ Descripción del proyecto

ELVA Beauty Academy es un sitio web diseñado para transmitir profesionalismo, elegancia y creatividad dentro del mundo de la belleza.

La plataforma permite a los visitantes conocer la academia, explorar sus formaciones, visualizar contenido multimedia y obtener información sobre las oportunidades de capacitación.

El diseño combina una estética minimalista con elementos visuales sofisticados, animaciones y una navegación intuitiva.

## 🚀 Características principales

- Diseño moderno, elegante y profesional.
- Interfaz totalmente responsive.
- Sección principal (Hero) con identidad visual.
- Presentación institucional de ELVA Beauty Academy.
- Sección de cursos y formaciones.
- Integración de contenido multimedia y videos.
- Galería visual.
- Preguntas frecuentes (FAQ).
- Navegación adaptable a dispositivos móviles.
- Animaciones y efectos de desplazamiento (Scroll).
- Optimización SEO para motores de búsqueda.
- Botones de contacto y consultas.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- YouTube Embed
- Git y GitHub Pages

## 🎨 Diseño y experiencia visual

El desarrollo utiliza una identidad visual enfocada en:
